
# 🎬 Netflix Data Analysis Project

This project explores Netflix data to uncover insights about countries producing most content, types of shows, and genre patterns.

## 🧠 Skills Demonstrated
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Data Cleaning & EDA
- Handling Missing Data
- Data Visualization
- Jupyter Notebook (VS Code)

## 📊 Key Insights
- 🇺🇸 USA and 🇮🇳 India have the most Netflix titles.
- 🎥 Movies dominate over TV Shows.
- 🎭 Dramas and Documentaries are the most popular genres.

##  Files Included
- `netflix_analysis.ipynb` → Jupyter Notebook with full analysis
- Dataset: [Netflix Titles Dataset on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
